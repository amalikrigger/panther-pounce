# Asset credits and licenses

## Original to Panther Pounce

These were made for this project and contain no third-party art:

| Asset | How it's made |
|---|---|
| sprites/*.png: the panther, ghoul, blocks, slingshot, smoke, buttons, popups, ground, bg, title and turndevice | Generated by [tools/make_sprites.py](../tools/make_sprites.py). Run `python tools/make_sprites.py` to rebuild them. |
| sprites/bird_split.png, zombie*.png, enemy_dmg*.png, wood1_dmg*.png, wood2_dmg*.png, glass1.png, glass2.png (split hex-cub, zombie heads, hurt looks, cracked wood, glass) | Generated by [tools/make_sprites.py](../tools/make_sprites.py) |
| sound/sound_cackle.wav (evil laugh when a level is lost) and sound/music_theme.wav (spooky ragtime background loop) | Synthesized by [tools/make_sounds.py](../tools/make_sounds.py). Run `python tools/make_sounds.py` to rebuild them. |
| World 2 levels | [js/levels/world2.js](../js/levels/world2.js) |
| Animated night background | Drawn in code by [js/render/parallax.js](../js/render/parallax.js) |
